Model

NodeWorks is a bounty board for DePIN compute. A poster locks a WBOT reward against a job spec URI and a delivery deadline; the contract holds the funds, so a node never works on a promise. Any node claims the open job, starting the deadline clock, and submits a result URI with its proof of execution.

Settlement is trust-minimized. The poster can approve the payout or dispute the result to the contract arbiter — but if the poster simply goes quiet, the worker self-settles through a three-day timeout and gets paid without anyone's permission. Every settled job bumps the worker's on-chain completedJobs counter, which other protocols (or agent policy engines like AgentVault) can read before routing work to a node.

Build & verify

cd botchain-builds/agent-vault
node build2.mjs                    # solc 0.8.30 → artifacts/nodeworks/*.bin|.abi
node deploy-2-mainnet.mjs          # deploy to chain 677 → deployed-mainnet-2.json
node demo-2-mainnet.mjs            # post + claim + submit + approve + dispute lifecycle
node make-flat-2.mjs               # SPDX-dedupe flatten + byte-match recompile
node submit-verify-2-mainnet.mjs   # POST flattened-code → scan.botchain.ai

Flatten output lives in agent-vault/verify2/*.flat.sol. Each flat was recompiled and byte-matched against the deployed runtime before submission (FLAT MATCH ×2).
